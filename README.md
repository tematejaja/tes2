# Skill: oferta-optima-contratacion-publica

Skill de Claude Code basada en la "Metodología para determinar una oferta óptima en contratación pública".

## Instalación global (en tu PC)

```bash
git clone <este-repo> && cd <este-repo>
git checkout claude/compassionate-brahmagupta-otrk3s
mkdir -p ~/.claude/skills
cp -r oferta-optima-contratacion-publica ~/.claude/skills/
```

En Windows (PowerShell): copiar la carpeta a `$env:USERPROFILE\.claude\skills\`.
Reinicia Claude Code y se invoca con `/oferta-optima-contratacion-publica` o automáticamente al hablar de precios de ofertas en licitaciones.
